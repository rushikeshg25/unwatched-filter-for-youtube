# Privacy Policy

**Unwatched Filter for YouTube**
Last updated: 18 September 2026

## The short version

This extension collects nothing, stores nothing and sends nothing anywhere.

## What it does

The extension adds an "Unwatched" filter to the Videos tab of YouTube
channel pages. When you turn the filter on, it reads the watch-progress
indicator YouTube already draws on each thumbnail and hides the videos that
have one, by adding and removing CSS classes on the page you are looking at.

All of this happens locally, in your browser, on the page itself.

## Data collection

**None.** Specifically, the extension does not collect, store, transmit or
sell any of the following:

- Personally identifiable information (name, address, email, age, ID number)
- Authentication information (passwords, credentials, security questions)
- Financial or payment information
- Health information
- Personal communications (email, messages, chats)
- Location data
- Web history or browsing activity
- User activity (clicks, mouse position, keystrokes, scroll)
- Website content (text, images, audio, video, hyperlinks)

The watch-progress indicators it reads are used only to decide, in the
moment, whether to hide a video from your own screen. They are never
recorded, aggregated or sent anywhere.

## Storage

Nothing is written to disk. The extension requests no `storage` permission.
Even whether the filter is currently on is held in memory and forgotten when
the tab closes.

## Network

The extension makes no network requests of any kind. It contains no
analytics, no telemetry, no error reporting and no third-party code. Every
line it runs is in the package you installed.

## Permissions

The extension requests **no permissions**. Its content script is declared
for `https://www.youtube.com/*` because the Videos tab of YouTube channels
is the only place it does anything. It has no access to any other site.

## Changes

Any change to these practices will be published here and reflected in a new
version of the extension.
